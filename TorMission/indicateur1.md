1️⃣ MODULE : Tendance H1

Ce module détecte :

les HH/HL pour les tendances haussières,

les LH/LL pour les tendances baissières,

les phases de compression ou d’indécision,

confirmation avec une moyenne mobile 50.

🔍 Les trois états possibles

🟢 Haussier (H1)
→ Structure propre + clôtures M1/M5/M15 au-dessus de la MA50 HTF.
Signification :

Contexte favorable aux achats,

Pullbacks M5/M15 sont plus fiables,

Les setups shorts doivent être considérés comme contre-tendance.

🔴 Baissier (H1)
→ Structure en LH/LL + clôtures sous la MA.
Signification :

Contexte favorable aux ventes,

Les rebonds haussiers sont faibles et régressifs.

🟠 Indécis / Range (H1)
→ Pas de structure claire.
Signification :

Le marché est en compression,

Les breakout traps sont fréquents,

Les liquidités M15 deviennent prioritaires pour éviter les pièges.

✔ Comment interpréter ce module ?

Plus la tendance H1 est nette, plus le score final augmente.

En scalping, on privilégie trader dans la direction H1.

En contre-tendance, on attend obligatoirement un signal Liquidité M15.

2️⃣ MODULE : Liquidité M15

Ce module détecte :

proximité des zones de liquidité,

sweeps potentiels,

déséquilibres violents (“Liquidity Void”),

tendances propres.

🔍 Les trois états possibles
🟦 Near Liquidity (M15)

→ Le prix est proche :

d’un plus haut M15 récent,

d’un plus bas M15 récent,

d’une zone de chasse évidente.

Signification :
⚠ Risque élevé de manipulation,
⚠ Les fausses cassures sont fréquentes,
🔎 Contexte parfait pour attendre un sweep avant d’entrer.

À trader avec prudence, c’est l'équivalent d’une zone piégée du marché.

🟪 Liquidity Void (M15)

→ Bougie de déséquilibre M15 anormalement grande.

Signification :

Le marché a laissé un vide,

Probabilité élevée de retour futur (Fill the Void),

Le prix n’est pas stable → breakouts dangereux.

C’est un signal anti-fomo.

🟩 Clean Trend (M15)

→ Pas de zone de liquidité proche + volatilité propre.
Signification :

Idéal pour trader avec la tendance H1,

Les retracements sont rationnels,

Le marché est propre → setups de continuité meilleurs.

3️⃣ MODULE : Session Power

Le module analyse l’énergie de la session en comparant la volatilité actuelle à la volatilité moyenne.

🔍 Les quatre états possibles :
⚪ Low Energy

Le marché est mort (souvent Asia tardive ou entre sessions).

Les mouvements sont faux et non directionnels.

🎯 NE PAS TRADER.

🟡 Medium Energy

Le marché se réveille,

Mouvements plus lisibles.

🎯 OK pour setups en tendance.

🟢 High Energy

Forte volatilité saine,

Session active (London open / NY open),

Les mouvements suivent la structure.

🎯 Contexte optimal pour trader.

🔴 Danger Spike

Volatilité trop forte,

Mouvements impulsifs non contrôlables,

Spreads qui s’élargissent,

Manipulations fréquentes.

🎯 Très dangereux → éviter.
